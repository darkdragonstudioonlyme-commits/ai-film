# V02 dev22 local-key reactivation audit criteria

Audit must verify design-to-review semantic immutability; the old activation remains historical/superseded; the exact durable key identity is machine-bound by private-derived-public parity, metadata and trust anchor; no private bytes enter Git/evidence; all V02 fail-closed controls remain; and native execution remains zero. Audit PASS may authorize exact deployment and a deployment receipt that includes key-parity PASS.
