# Immutable Learning Records

Use `LEARNING-<scope>-<nnn>.md` for reusable learning that needs durable evidence/provenance beyond the compact `PROJECT_MEMORY.md` index.

Each record follows `SELF_LEARNING.md`, including root cause, evidence, reusable rule, score, policy/tool promotion, success metric, review status and lifecycle status. Superseded/retired learning links its successor when applicable.

`PROJECT_MEMORY.md` contains only active compact entries and pointers; detailed learning history remains here, in immutable review/health records, or Git history.
