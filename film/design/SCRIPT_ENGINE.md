# Script Engine

Input: rough premise or licensed source extract. Output: logline → beat sheet → screenplay → localized dialogue.
For slice01 the master screenplay is English; ZH/VI are localized for timing and intent, not literal word-for-word translation.
Required scene fields: purpose, conflict, turn, character objective, story_time, estimated seconds.
Quality review checks hook, clarity, emotional turn, dialogue economy and whether every shot changes story information.
A critique pass may propose revisions; the coordinator chooses one revision, avoiding recursive review loops.
Acceptance: target runtime 60–90s, no unresolved rights issue, each dialogue line has a stable ID for localization/TTS.
