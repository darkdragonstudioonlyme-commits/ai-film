# Casting and Look

Each character has a stable visual description, language-specific voice profile and optional reference assets.
Photoreal and stylized-3D are separate benchmark presets; do not blend them in a single scored run.
Casting evaluation measures within-character similarity and between-character separation.
Reference files are immutable assets with manifests; costume references are not identity references.
Slice01 may use placeholders until GPU benchmark selects an image stack.
Acceptance: two characters are visually distinguishable and each retains identity across the fixed benchmark set.
