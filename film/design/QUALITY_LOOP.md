# Quality Loop

Every take stores shot spec, compiled prompt, refs, model/version, seed, cost/time, QC result and human score.
After the first complete film, establish a fixed evaluation set and champion baseline.
Experiments change one material variable where possible and compare against held-out shots/sequences.
Promote only when target quality improves without unacceptable regressions or cost/throughput breach; otherwise revert.
FILM_LEARNINGS.md receives only measured lessons with population and before/after values.
Acceptance: a claimed improvement is reproducible on the named eval set and linked to immutable manifests.
